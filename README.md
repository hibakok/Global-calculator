Global Calculator
Многофункциональный и удобный калькулятор на чистом Python. Цель — самый многофункциональный и удобный калькулятор, построенный из предельно малых и понятных методов-кирпичиков.

Принципы проекта
Минимализм методов. Каждый метод выполняет одну простую функцию. Более сложные методы собираются из более простых, как из кирпичиков.
Ветви кода. Программа делится на изолированные ветви. Каждая ветвь — это цепочка: сложный метод опирается на более простые, те — на ещё более простые, и так до предела простоты.
Без сторонних библиотек. Только стандартная библиотека Python.
Структура — в текстовых файлах. Раздел docs/ описывает структуру репозитория и каждый метод: входные данные, выходные данные, функцию.
Один метод — одно изменение. Репозиторий развивается минимальными шагами, каждый шаг проверяется тестами.
Как ориентироваться

Как запустить
python run.py
Откроется цикл ввода: печатайте выражения (2 + 2 * 2, sqrt(16), x = 4, ans * 2) и получайте результат. Команда help (также справка или ?) показывает справку по выражениям, функциям и переменным. Команды выхода: exit, quit, выход.

Как запустить тесты
python -m unittest discover -s tests -v
Тесты также запускаются автоматически на каждый коммит и pull request (GitHub Actions). Зелёная галочка у коммита — всё в порядке.

Статус
Точный статус ветвей и очередь следующих шагов — всегда в docs/roadmap.txt (это единственное место, где ведутся статусы).
