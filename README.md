Global Calculator
Многофункциональный и удобный калькулятор на чистом Python.Цель — самый многофункциональный и удобный калькулятор, построенныйиз предельно малых и понятных методов-кирпичиков.

Принципы проекта
Минимализм методов. Каждый метод выполняет одну простую функцию.Более сложные методы собираются из более простых, как из кирпичиков.
Ветви кода. Программа делится на изолированные ветви. Каждаяветвь — это цепочка: сложный метод опирается на более простые,те — на ещё более простые, и так до предела простоты.
Без сторонних библиотек. Только стандартная библиотека Python.
Структура — в текстовых файлах. Раздел docs/ описываетструктуру репозитория и каждый метод: входные данные, выходныеданные, функцию.
Один метод — одно изменение. Репозиторий развиваетсяминимальными шагами, каждый шаг проверяется тестами.

Как запустить тесты
python -m unittest discover -s tests -v
Тесты также запускаются автоматически на каждый коммит и pullrequest (GitHub Actions). Зелёная галочка у коммита — всё в порядке.
