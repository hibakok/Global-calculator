Global Calculator
Многофункциональный и удобный калькулятор на чистом Python.

Принципы проекта
Минимализм методов. Каждый метод выполняет одну простую функцию.Более сложные методы собираются из более простых, как из кирпичиков.
Ветви кода. Программа делится на изолированные ветви. Каждая ветвь —это цепочка: сложный метод опирается на более простые, те на ещё болеепростые, и так до предела простоты.
Без сторонних библиотек. Используется только стандартная библиотекаPython.
Структура — в текстовых файлах. Раздел docs/ описывает структурурепозитория и каждый метод: входные данные, выходные данные, функцию.
Один метод — одно изменение. Репозиторий развивается минимальнымишагами.
Как ориентироваться
Карта репозитория: docs/structure.txt
Описания методов: `docs/branches/<имя ветви>.txt
