----------------------------------------------------------------
ВЕТВИ КОДА

Программа делится на изолированные ветви: branch_1, branch_2, ...
Каждая ветвь — это файл кода, файл описания и файл тестов.
Полный план ветвей, их статусы и очередь шагов — в docs/roadmap.txt.

----------------------------------------------------------------
ФОРМАТ ОПИСАНИЯ МЕТОДА

Каждый метод описывается в файле своей ветви так:

METHOD:       <имя метода>
INPUT DATA:   <что получает>
OUTPUT DATA:  <что возвращает>
FUNCTION:     <что делает>

----------------------------------------------------------------
ПРАВИЛО ИЗМЕНЕНИЙ

Одно изменение репозитория = один метод или одна подветвь
(связная группа методов). Полный состав шага описан в
AGENTS.md, раздел «Как добавить метод».

----------------------------------------------------------------
КАК ПРОВЕРИТЬ

Локально:   python -m unittest discover -s tests -v
На GitHub:  тесты запускаются автоматически (вкладка Actions),
            итог виден галочкой у коммита.
