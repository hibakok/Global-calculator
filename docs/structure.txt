ВЕТВИ КОДА (план)

Ветвь 1. Элементарная арифметика
    add, subtract, multiply, divide и другие элементарные операции.
    Статус: не начата.

Ветвь 2. Расширенная арифметика
    Степень, корень, процент, целочисленное деление, остаток.
    Собирается из методов Ветви 1.
    Статус: не начата.

Ветвь 3. Разбор выражений
    Преобразование строки вида "2 + 2 * 2" в результат.
    Токенизатор, парсер, вычислитель.
    Статус: не начата.

Ветвь 4. Научные функции
    Тригонометрия, логарифмы, экспонента — собственные реализации
    через ряды, без сторонних библиотек.
    Статус: не начата.

Ветвь 5. Память и история
    Хранение промежуточных результатов, история операций.
    Статус: не начата.

Ветвь 6. Преобразования
    Системы счисления, единицы измерения.
    Статус: не начата.

Ветвь 7. Консольный интерфейс
    Меню и цикл команд. Собирается из всех ветвей выше.
    Статус: не начата.

----------------------------------------------------------------
ФОРМАТ ОПИСАНИЯ МЕТОДА

Каждый метод описывается в файле своей ветви так:

METHOD:       <имя метода>
INPUT DATA:   <что получает>
OUTPUT DATA:  <что возвращает>
FUNCTION:     <что делает>

ПРАВИЛО ИЗМЕНЕНИЙ

Одно изменение репозитория = один метод: код + его запись в файле
ветви. Файл ветви создаётся вместе с первым методом этой ветви.
