================================================================
ВЕТВЬ 5. ТРИГОНОМЕТРИЯ
================================================================

Файл кода ветви: src/branch_5_trigonometry.py
Число пи по формуле Мэчина, приведение угла к малому диапазону,
синус, косинус и тангенс собственными рядами Тейлора. Собирается
из Ветви 1 (add, subtract, multiply, divide) и Ветви 4 (abs_value).

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       arctan_series(z)
INPUT DATA:   число z (int или float) из интервала (-1, 1)
OUTPUT DATA:  число (float) — сумма ряда z - z^3/3 + z^5/5 - ...,
              то есть arctan(z); при z <= -1 или z >= 1 —
              исключение ValueError; при nan — nan
FUNCTION:     суммирует ряд Тейлора арктангенса: каждый следую-
              щий член получается из предыдущего умножением на
              z^2 и на (2k-1)/(2k+1) со сменой знака. Границы
              интервала отвергаются явно: на них ряд сходится
              бесконечно долго. Для z = 1/5 сходится за ~25
              членов. Собран из add, subtract, multiply, divide,
              abs_value
----------------------------------------------------------------
METHOD:       get_pi()
INPUT DATA:   нет
OUTPUT DATA:  число (float) — число пи
FUNCTION:     возвращает пи по формуле Мэчина:
              pi = 16 * arctan(1/5) - 4 * arctan(1/239).
              Оба аргумента малы, поэтому ряды сходятся быстро
              (~25 и ~8 членов). get_pi() ≈ 3.141592653589793
              (погрешность ~1e-15). Собран из arctan_series,
              add, subtract, multiply, divide
----------------------------------------------------------------
METHOD:       reduce_angle(x)
INPUT DATA:   угол x в радианах (int, float, nan)
OUTPUT DATA:  пара (k, r): целое число k и число r, такие что
              x = k * pi + r и |r| <= pi/2; при nan — (0, nan);
              при бесконечном x — исключение ValueError
FUNCTION:     приводит угол к малому диапазону для быстрых
              рядов: k = округлённое x / pi, r = x - k * pi.
              Замечание о точности: при очень больших |x|
              (порядка 1e6 и больше) вычитание k * pi теряет
              точные цифры, и погрешность растёт примерно как
              |x| * 1e-16 — это фундаментальное ограничение
              двойной точности, задокументировано честно.
              Собран из get_pi, divide, subtract, multiply
----------------------------------------------------------------
METHOD:       sin_series(r)
INPUT DATA:   число r (int или float), по модулю не больше pi/2
OUTPUT DATA:  число (float) — сумма ряда r - r^3/3! + r^5/5! - ...;
              при nan — nan
FUNCTION:     суммирует ряд Тейлора синуса: каждый следующий
              член получается из предыдущего умножением на r^2
              и делением на (2k)(2k+1) со сменой знака. Для
              |r| <= pi/2 сходится за ~10 членов. Собран из
              add, subtract, multiply, divide, abs_value
----------------------------------------------------------------
METHOD:       cos_series(r)
INPUT DATA:   число r (int или float), по модулю не больше pi/2
OUTPUT DATA:  число (float) — сумма ряда 1 - r^2/2! + r^4/4! - ...;
              при nan — nan
FUNCTION:     суммирует ряд Тейлора косинуса: каждый следующий
              член получается из предыдущего умножением на r^2
              и делением на (2k-1)(2k) со сменой знака. Для
              |r| <= pi/2 сходится за ~10 членов. Собран из
              add, subtract, multiply, divide, abs_value
----------------------------------------------------------------
METHOD:       sin_rad(x)
INPUT DATA:   угол x в радианах (int, float, nan)
OUTPUT DATA:  число (float) — синус x; при nan — nan;
              при бесконечном x — исключение ValueError
FUNCTION:     синус любого угла: приводит угол reduce_angle к
              малому диапазону, суммирует sin_series и меняет
              знак, если k нечётно (sin(k*pi + r) =
              (-1)^k * sin(r)). Погрешность ~1e-15 для умеренных
              |x|; sin_rad(pi) = 0 точно. Собран из reduce_angle,
              sin_series, subtract
----------------------------------------------------------------
METHOD:       cos_rad(x)
INPUT DATA:   угол x в радианах (int, float, nan)
OUTPUT DATA:  число (float) — косинус x; при nan — nan;
              при бесконечном x — исключение ValueError
FUNCTION:     косинус любого угла: приводит угол reduce_angle к
              малому диапазону, суммирует cos_series и меняет
              знак, если k нечётно (cos(k*pi + r) =
              (-1)^k * cos(r)). cos_rad(pi) = -1 точно.
              Собран из reduce_angle, cos_series, subtract
----------------------------------------------------------------
METHOD:       tan_rad(x)
INPUT DATA:   угол x в радианах (int, float, nan)
OUTPUT DATA:  число (float) — тангенс x; при nan — nan;
              при бесконечном x — исключение ValueError
FUNCTION:     тангенс как деление синуса на косинус:
              tan_rad(x) = sin_rad(x) / cos_rad(x). В полюсах
              x = pi/2 + k*pi тангенс не определён: результат
              может быть огромным числом (как у стандартной
              библиотеки) или исключением ZeroDivisionError.
              Собран из sin_rad, cos_rad, divide
----------------------------------------------------------------
ЗАМЕЧАНИЕ О ТОЧНОСТИ

Погрешности измерены сравнением с эталоном (модуль math,
см. тесты): arctan_series, sin_series, cos_series — около
5e-16; get_pi — около 1e-15; sin_rad и cos_rad — около 1e-15
при |x| <= 10 и растёт примерно как |x| * 1e-16 дальше
(ограничение приведения угла, см. reduce_angle).
