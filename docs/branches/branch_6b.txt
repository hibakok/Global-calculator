================================================================
ВЕТВЬ 6B. НАУЧНЫЕ ВЫРАЖЕНИЯ: ТАБЛИЦЫ ИМЁН, ОПЕРАЦИИ И ПАРСЕР
================================================================

Файл кода подветви: src/branch_6b_scientific_parser.py
Даёт смысл именам из подветви 6a: константы pi и e, функции
sqrt, exp, ln, sin, cos, tan. Операция "^" возводит в вещественную
степень через power_real Ветви 4. Главная функция —
calculate_scientific: строка научного выражения -> число.
Собирается из методов Ветвей 1, 3b, 4, 5 и 6a.

----------------------------------------------------------------
МЕТОДЫ ПОДВЕТВИ

METHOD:       apply_scientific(op, a, b)
INPUT DATA:   символ операции op (один из + - * / % ^) и числа a, b
OUTPUT DATA:  результат бинарной операции; "^" — вещественная
              степень; при делении на ноль — ZeroDivisionError,
              при неизвестной операции — ValueError
FUNCTION:     аналог apply_binary Ветви 3b для научных выражений:
              все операции, кроме "^", делегирует apply_binary,
              а "^" направляет в power_real Ветви 4 — так в
              научном режиме появляется вещественная степень
              (2 ^ 0.5 = 1.4142...). Собран из apply_binary,
              power_real
----------------------------------------------------------------
METHOD:       is_constant(name)
INPUT DATA:   имя name (строка)
OUTPUT DATA:  True для pi и e, иначе False
FUNCTION:     кирпич таблицы имён: распознаёт константу.
              Парсер спрашивает сначала is_function, затем
              is_constant и только потом constant_value —
              каждый метод остаётся предельно простым
----------------------------------------------------------------
METHOD:       constant_value(name)
INPUT DATA:   имя константы: pi или e
OUTPUT DATA:  число — значение константы; при неизвестном имени —
              ValueError
FUNCTION:     таблица констант научного режима. Значения
              вычисляются методами Ветвей 4-5: pi — get_pi
              (формула Мэчина), e — get_e. Собран из get_pi, get_e
----------------------------------------------------------------
METHOD:       is_function(name)
INPUT DATA:   имя name (строка)
OUTPUT DATA:  True для sqrt, exp, ln, sin, cos, tan; иначе False
FUNCTION:     кирпич таблицы имён: распознаёт имя функции.
              Зеркально is_constant
----------------------------------------------------------------
METHOD:       apply_function(name, x)
INPUT DATA:   имя функции (sqrt, exp, ln, sin, cos, tan) и число x
OUTPUT DATA:  значение функции в точке x; при неизвестном имени —
              ValueError; ошибки области определения (sqrt(-1),
              ln(0)) проходят насквозь из Ветвей 4-5
FUNCTION:     таблица функций научного режима: sqrt — sqrt_real,
              exp — exp_real, ln — ln_positive, sin — sin_rad,
              cos — cos_rad, tan — tan_rad. Собран из методов
              Ветвей 4 и 5
----------------------------------------------------------------
METHOD:       parse_call(tokens, pos)
INPUT DATA:   список токенов и позиция токена-имени функции
OUTPUT DATA:  пара (значение, позиция за закрывающей скобкой);
              при отсутствующих скобках — ValueError
FUNCTION:     разбор вызова функции: имя, "(", выражение-аргумент,
              ")". Аргумент — полное выражение, поэтому допустимы
              sin(pi/2) и sqrt(2 + 2). Собран из current_token,
              parse_expression_scientific, apply_function
----------------------------------------------------------------
METHOD:       parse_factor_scientific(tokens, pos)
INPUT DATA:   список токенов и позиция
OUTPUT DATA:  пара (значение, позиция); при ошибке разбора —
              ValueError ("Неизвестное имя", "Ожидалась
              закрывающая скобка" и другие)
FUNCTION:     множитель научного выражения: число; константа
              (pi, e); вызов функции; унарный + или -; скобка.
              Зеркально parse_factor Ветви 3b плюс ветка имени.
              Унарный минус применяется к степени: -2 ^ 2 = -4.
              Собран из current_token, is_function, parse_call,
              is_constant, constant_value, subtract,
              parse_power_scientific, parse_expression_scientific
----------------------------------------------------------------
METHOD:       parse_power_scientific(tokens, pos)
INPUT DATA:   список токенов и позиция
OUTPUT DATA:  пара (значение, позиция)
FUNCTION:     вещественная степень, правоассоциативно:
              2 ^ 3 ^ 2 = 2 ^ (3 ^ 2) = 512. Собран из
              parse_factor_scientific, current_token,
              apply_scientific
----------------------------------------------------------------
METHOD:       parse_term_scientific(tokens, pos)
INPUT DATA:   список токенов и позиция
OUTPUT DATA:  пара (значение, позиция)
FUNCTION:     цепочка умножения, деления и остатка слева направо.
              Собран из parse_power_scientific, current_token,
              apply_scientific
----------------------------------------------------------------
METHOD:       parse_expression_scientific(tokens, pos)
INPUT DATA:   список токенов и позиция
OUTPUT DATA:  пара (значение, позиция)
FUNCTION:     цепочка сложения и вычитания слева направо —
              верхний уровень научного парсера. Собран из
              parse_term_scientific, current_token,
              apply_scientific
----------------------------------------------------------------
METHOD:       calculate_scientific(s)
INPUT DATA:   строка научного выражения, например
              "sqrt(2) + sin(pi/2)"
OUTPUT DATA:  число — значение выражения; при пустой строке или
              неполном разборе — ValueError; при делении на ноль —
              ZeroDivisionError
FUNCTION:     главная функция научного режима: токенизирует
              строку tokenize_scientific, требует непустой список
              токенов, вычисляет parse_expression_scientific
              и требует разбор до конца.
              calculate_scientific("sqrt(2) + sin(pi/2)") =
              2.414213562373095. Собран из tokenize_scientific,
              parse_expression_scientific
----------------------------------------------------------------
ПРИМЕЧАНИЕ

Унарный минус слабее степени: -2 ^ 2 = -4; для противоположного
знака основания нужны скобки: (-2) ^ 2 = 4. Отрицательное
основание в дробной степени — ValueError (наследуется из
power_real Ветви 4). Функция требует скобок: "sqrt 2" — ошибка.
Примеры: calculate_scientific("2 ^ 0.5") = 1.4142135623730956,
calculate_scientific("ln(e ^ 3)") = 3.0000000000000013,
calculate_scientific("-(2 + 3) ^ 2") = -25.
