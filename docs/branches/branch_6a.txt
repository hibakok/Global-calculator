================================================================
ВЕТВЬ 6A. НАУЧНЫЕ ВЫРАЖЕНИЯ: ТОКЕНИЗАТОР
================================================================

Файл кода подветви: src/branch_6a_scientific_tokenizer.py
Расширяет токенизатор Ветви 3a для научных выражений: имена
(sqrt, pi, sin) и числа с показателем степени (1e3, 2.5e-4).
Подветвь 6a не знает ни констант, ни функций — она только делит
строку на токены; смысл именам даёт подветвь 6b. Токенизатор
Ветви 3a не изменяется: научные кирпичи (буквы имён, показатели
степени) живут здесь.

----------------------------------------------------------------
МЕТОДЫ ПОДВЕТВИ

METHOD:       is_letter(c)
INPUT DATA:   символ c (строка длины 1)
OUTPUT DATA:  True, если c — латинская буква a-z, A-Z; иначе False
FUNCTION:     кирпич имён: распознаёт букву так же, как is_digit
              Ветви 3a распознаёт цифру. Имена функций и констант
              научных выражений состоят только из латинских букв
              (sqrt, pi, sin); регистр учитывается.
----------------------------------------------------------------
METHOD:       read_name(s, i)
INPUT DATA:   строка s и позиция i, где начинается имя
OUTPUT DATA:  позиция, идущая за последовательностью латинских
              букв, начатой в позиции i; если s[i] — не буква,
              возвращает i без изменений
FUNCTION:     пропускает имя в строке — зеркально read_digits
              Ветви 3a. Само имя не возвращает: текст имени —
              это срез s[i:end], его вырезает read_token_scientific
----------------------------------------------------------------
METHOD:       is_exponent_letter(c)
INPUT DATA:   символ c (строка длины 1)
OUTPUT DATA:  True, если c — буква показателя степени: e или E
FUNCTION:     кирпич чисел с показателем: обе буквы допустимы,
              1e3 и 1E3 — одно и то же число 1000
----------------------------------------------------------------
METHOD:       has_exponent(s, j)
INPUT DATA:   строка s и позиция j сразу за мантиссой числа
OUTPUT DATA:  True, если в позиции j начинается показатель
              степени: буква e/E, за которой цифра, либо знак
              + или - с цифрой за ним; иначе False
FUNCTION:     отличает показатель степени от имени: в "1e3"
              буква e с цифрой — показатель (число 1000), а в
              "1e" буква e без цифры — начало имени константы e.
              Проверяет границы строки. Собран из
              is_exponent_letter, is_digit
----------------------------------------------------------------
METHOD:       exponent_digits_start(s, j)
INPUT DATA:   строка s и позиция j буквы e/E начала показателя
              степени (уже проверенного has_exponent)
OUTPUT DATA:  позиция первой цифры показателя степени: j+1 без
              знака, j+2 после знака + или -
FUNCTION:     вычисляет, откуда читать цифры показателя;
              вызывается только после has_exponent(s, j) == True
----------------------------------------------------------------
METHOD:       read_number_exp(s, i)
INPUT DATA:   строка s и позиция i, где начинается число
OUTPUT DATA:  пара (число, следующая позиция): без показателя —
              как read_number Ветви 3a (целое или с точкой),
              с показателем — float: 1e3 -> 1000.0,
              2.5e-4 -> 0.00025; чрезмерный показатель даёт
              inf (1e400) или 0.0 (1e-400)
FUNCTION:     расширяет read_number Ветви 3a показателем
              степени: читает мантиссу, затем (если есть)
              e/E с необязательным знаком и цифрами; значение
              разбирает встроенным float() из среза строки.
              Собран из read_number, has_exponent,
              exponent_digits_start, read_digits
----------------------------------------------------------------
METHOD:       read_token_scientific(s, i)
INPUT DATA:   строка s и позиция i первого символа токена
OUTPUT DATA:  пара (токен, следующая позиция): ("number", ...)
              для числа с показателем, ("name", текст) для
              последовательности букв, остальные токены — как
              у read_token Ветви 3a (операции, скобки);
              при недопустимом символе — ValueError
FUNCTION:     читает один токен научного выражения: цифра
              направляет к read_number_exp, буква — к read_name,
              всё остальное достаётся read_token Ветви 3a
              (операции, скобки, сообщения об ошибках).
              Собран из is_digit, read_number_exp, is_letter,
              read_name, make_token, read_token
----------------------------------------------------------------
METHOD:       tokenize_with(s, read_one)
INPUT DATA:   строка s и функция чтения одного токена read_one:
              принимает (s, i), возвращает (токен, следующая
              позиция)
OUTPUT DATA:  список токенов всей строки; пробелы игнорируются
FUNCTION:     универсальный цикл токенизации: читает токены
              read_one, пока строка не кончится. Один цикл
              обслуживает и tokenize Ветви 3a, и
              tokenize_scientific — без изменения Ветви 3a.
              Собран из skip_spaces
----------------------------------------------------------------
METHOD:       tokenize_scientific(s)
INPUT DATA:   строка научного выражения, например
              "sqrt(2) + sin(pi/2)"
OUTPUT DATA:  список токенов: числа (в том числе 1e3), имена
              (pi, sqrt, sin), операции + - * / % ^, скобки;
              при недопустимом символе — ValueError
FUNCTION:     разбирает строку научного выражения в список
              токенов — главный токенизатор научного режима.
              Собран из tokenize_with, read_token_scientific
----------------------------------------------------------------
ПРИМЕЧАНИЕ

Числа без показателя остаются целыми (42 -> int), как в Ветви 3a.
Имена регистрозависимы: pi и e — имена констант, sqrt и sin —
имена функций; их смысл определяет подветвь 6b. Шестнадцатеричные
числа (0x1F) не поддерживаются: показатель степени пишется только
буквами e/E.
