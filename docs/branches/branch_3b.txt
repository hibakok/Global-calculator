================================================================
ВЕТВЬ 3B. РАЗБОР ВЫРАЖЕНИЙ: ПАРСЕР И ВЫЧИСЛИТЕЛЬ
================================================================

Файл кода ветви: src/branch_3b_parser.py
Верхний уровень Ветви 3. Вычисляет значение выражения по списку
токенов Ветви 3a. Собирается из Ветвей 1, 2 и 3a.

Грамматика (приоритет от низкого к высокому):
  выражение  = слагаемое ((+|-) слагаемое)*
  слагаемое  = степенное ((*|/|%) степенное)*
  степенное  = множитель (^ степенное)?          правоассоциативно
  множитель  = число | ( выражение ) | (-|+) степенное

Соглашения:
  - унарный минус слабее степени: -2 ^ 2 = -4;
  - степень правоассоциативна: 2 ^ 3 ^ 2 = 512;
  - "^" принимает целые показатели; вещественная степень
    появится в Ветви 4.

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       current_token(tokens, pos)
INPUT DATA:   список токенов tokens; позиция pos (int)
OUTPUT DATA:  токен на позиции pos; если позиция за концом
              списка — токен ("end", None)
FUNCTION:     безопасно читает текущий токен, не выходя за
              границы списка
----------------------------------------------------------------
METHOD:       power_signed(a, n)
INPUT DATA:   число a; целое число n (int)
OUTPUT DATA:  число — a в степени n; при нецелом n —
              исключение ValueError
FUNCTION:     возводит a в целую степень, включая отрицательную:
              power_signed(2, -2) = 0.25. Собран из кирпичиков
              power_int, divide, subtract
----------------------------------------------------------------
METHOD:       apply_binary(op, a, b)
INPUT DATA:   знак операции op (одна из + - * / % ^); числа a, b
OUTPUT DATA:  число — результат операции; при делении и остатке
              на ноль — ZeroDivisionError; при неизвестной
              операции — ValueError
FUNCTION:     применяет бинарную операцию к двум числам;
              распределяет по кирпичикам Ветвей 1-2: add,
              subtract, multiply, divide, remainder, power_signed
----------------------------------------------------------------
METHOD:       parse_factor(tokens, pos)
INPUT DATA:   список токенов tokens; позиция pos (int)
OUTPUT DATA:  пара (значение, следующая позиция); при
              синтаксической ошибке — исключение ValueError
FUNCTION:     разбирает множитель: число, выражение в скобках
              или унарный знак перед степенью (-2 ^ 2 = -4)
----------------------------------------------------------------
METHOD:       parse_power(tokens, pos)
INPUT DATA:   список токенов tokens; позиция pos (int)
OUTPUT DATA:  пара (значение, следующая позиция)
FUNCTION:     разбирает возведение в степень; правоассоциативно
              за счёт рекурсии: 2 ^ 3 ^ 2 = 512. Собран из
              parse_factor и apply_binary
----------------------------------------------------------------
METHOD:       parse_term(tokens, pos)
INPUT DATA:   список токенов tokens; позиция pos (int)
OUTPUT DATA:  пара (значение, следующая позиция)
FUNCTION:     разбирает цепочку умножений, делений и остатков
              слева направо: 2 * 3 * 4 = 24
----------------------------------------------------------------
METHOD:       parse_expression(tokens, pos)
INPUT DATA:   список токенов tokens; позиция pos (int)
OUTPUT DATA:  пара (значение, следующая позиция)
FUNCTION:     разбирает цепочку сложений и вычитаний слева
              направо: 1 + 2 - 3
----------------------------------------------------------------
METHOD:       calculate(s)
INPUT DATA:   строка s с арифметическим выражением
OUTPUT DATA:  число (int или float) — значение выражения;
              при пустой строке, недопустимом символе или
              синтаксической ошибке — исключение ValueError
FUNCTION:     главная функция калькулятора: tokenize, полный
              разбор и проверка, что использованы все токены;
              calculate("2 + 2 * 2") = 6
