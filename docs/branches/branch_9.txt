================================================================
ВЕТВЬ 9. КОНСОЛЬНЫЙ ИНТЕРФЕЙС: ЦИКЛ ВВОДА И СПРАВКА
================================================================

Файл кода ветви: src/branch_9_console.py
Точка запуска программы: run.py (из корня репозитория,
python run.py). Собирается из методов Ветви 7 (make_session,
calculate_session) — то есть транзитивно из всего вычислительного
ядра: арифметика, научные функции, переменные, ans, история.
Существующие ветви не изменяются.

Часть 1 — живой цикл ввода (REPL): строка ввода вычисляется
в сессии, результат печатается строкой «= число»; ошибки
вычисления печатаются сообщением «Ошибка: ...» и не завершают
цикл и не оставляют следов в сессии (это гарантирует
calculate_session Ветви 7). Пустые строки пропускаются молча.
Выход — команда exit, quit, выход (регистр и пробелы не важны)
или конец ввода (Ctrl+D); Ctrl+C в ожидании ввода тоже завершает
работу.

Часть 2 — справка и понятный вывод ошибок. Команда help
(также справка и ?) печатает справку по командам, записи
выражений, функциям, константам и переменным; справка собрана
из отдельных кирпичиков-разделов, и Ветвь 17 (удобство) сможет
дополнять её новыми разделами. Вывод ошибок стал понятнее:
explain_error переводит RecursionError (глубокая вложенность
скобок или функций) в русский текст, и line_output ловит его
наравне с ошибками вычисления — цикл не падает ни на каком
вводе. Команда справки сверяется со всей строкой целиком,
поэтому присваивание «help = 5» по-прежнему работает.

Пример сеанса:

  python run.py
  Global Calculator. Введите выражение; help — справка, exit — выход.
  > help
  Команды:
    help, справка, ?  — показать эту справку
    exit, quit, выход — завершить работу

  Выражения:
    числа: 42, 3.14, 1e3, 2.5e-2
    операции: + - * / % (остаток); ^ — степень
    скобки: (2 + 2) * 3; унарные знаки: -2, +2
    приоритет: ^ выше * / %, те выше + -;
    степень считается справа налево: 2^3^2 = 512

  Функции (углы — в радианах):
    sqrt(x), exp(x), ln(x), sin(x), cos(x), tan(x)
  Константы:
    pi, e

  Переменные:
    x = 2 + 2  — присваивание (имя из латинских букв)
    a = b = 2  — цепочка присваиваний
    x * 3      — использование переменной
    ans        — последний результат: ans * 2
  > 2^3^2
  = 512
  > 1 / 0
  Ошибка: Деление на ноль запрещено.
  > выход

КОНСТАНТЫ (создаются при загрузке модуля, никогда не изменяются;
глобального изменяемого состояния нет — docs/conventions.txt,
раздел 6):
  EXIT_COMMANDS  кортеж команд выхода: "exit", "quit", "выход"
  HELP_COMMANDS  кортеж команд справки: "help", "справка", "?"
  PROMPT         строка приглашения ввода: "> "
  GREETING       строка приветствия при запуске main
  RESULT_PREFIX  префикс успешного результата: "= "
  ERROR_PREFIX   префикс сообщения об ошибке: "Ошибка: "

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       is_exit_command(line)
INPUT DATA:   строка ввода line
OUTPUT DATA:  True, если line — команда выхода (exit, quit,
              выход; регистр и крайние пробелы не важны),
              иначе False
FUNCTION:     предикат команды выхода; используется run_repl
----------------------------------------------------------------
METHOD:       is_help_command(line)
INPUT DATA:   строка ввода line
OUTPUT DATA:  True, если line — команда справки (help, справка
              или ?; регистр и крайние пробелы не важны),
              иначе False
FUNCTION:     предикат команды справки; сверяется со всей
              строкой целиком, поэтому «help = 5» командой
              не является; используется line_output
----------------------------------------------------------------
METHOD:       is_blank(line)
INPUT DATA:   строка ввода line
OUTPUT DATA:  True, если line пустая или из одних пробелов,
              иначе False
FUNCTION:     предикат пустой строки; используется line_output,
              чтобы пропустить ввод без ответа
----------------------------------------------------------------
METHOD:       help_commands_text()
INPUT DATA:   нет
OUTPUT DATA:  строка — раздел справки о командах программы
FUNCTION:     кирпичик справки: перечисляет команды help
              и exit; разделы соединяет help_text
----------------------------------------------------------------
METHOD:       help_syntax_text()
INPUT DATA:   нет
OUTPUT DATA:  строка — раздел справки о записи выражений
FUNCTION:     кирпичик справки: числа (в том числе 1e3),
              операции, скобки, приоритет и ассоциативность
              степени
----------------------------------------------------------------
METHOD:       help_functions_text()
INPUT DATA:   нет
OUTPUT DATA:  строка — раздел справки о функциях и константах
FUNCTION:     кирпичик справки: список функций (углы —
              в радианах) и констант; при расширении таблиц
              имён Ветви 6b раздел дополняется
----------------------------------------------------------------
METHOD:       help_variables_text()
INPUT DATA:   нет
OUTPUT DATA:  строка — раздел справки о переменных и ans
FUNCTION:     кирпичик справки: присваивание, цепочки,
              использование переменных и последний результат
----------------------------------------------------------------
METHOD:       help_text()
INPUT DATA:   нет
OUTPUT DATA:  строка — полный текст справки
FUNCTION:     собирает справку из четырёх разделов,
              соединяя их пустой строкой
----------------------------------------------------------------
METHOD:       format_value(value)
INPUT DATA:   число value — int или float
OUTPUT DATA:  строка вывода: целые float печатаются без точки
              (4.0 -> "4"), прочие числа — str(value)
FUNCTION:     кирпичик форматирования результата; шаги Ветви 17
              (удобство) будут расширять вывод, не меняя этот
              контракт
----------------------------------------------------------------
METHOD:       result_text(value)
INPUT DATA:   число value — результат вычисления
OUTPUT DATA:  строка успешного ответа: "= " и format_value(value)
FUNCTION:     собирает текст результата из константы и кирпичика
----------------------------------------------------------------
METHOD:       explain_error(error)
INPUT DATA:   исключение error из вычисления строки
OUTPUT DATA:  понятное сообщение об ошибке: для RecursionError —
              «Слишком глубокая вложенность скобок или
              функций.», прочее — текст исключения
FUNCTION:     кирпичик понятного вывода ошибок; используется
              error_text
----------------------------------------------------------------
METHOD:       error_text(error)
INPUT DATA:   исключение error из вычисления строки
OUTPUT DATA:  строка сообщения: "Ошибка: " и explain_error(error)
FUNCTION:     собирает текст ошибки из константы и кирпичика
              понятных сообщений
----------------------------------------------------------------
METHOD:       line_output(line, session)
INPUT DATA:   строка ввода line и сессия session (Ветвь 7)
OUTPUT DATA:  строка-ответ (результат, справка или ошибка)
              либо None, если строка пустая
FUNCTION:     ядро ответа на одну строку ввода: пустая — None;
              команда справки — help_text; иначе calculate_session
              и result_text. Ловит ValueError, TypeError,
              ArithmeticError (в него входят ZeroDivisionError
              и OverflowError) и RecursionError — цикл не падает
              ни на каком вводе
----------------------------------------------------------------
METHOD:       read_line()
INPUT DATA:   нет (читает стандартный ввод)
OUTPUT DATA:  введённая строка либо None при конце ввода (Ctrl+D)
              или прерывании (Ctrl+C)
FUNCTION:     кирпичик чтения ввода с приглашением PROMPT;
              завершение ввода переводится в None, чтобы run_repl
              не знал про исключения ввода
----------------------------------------------------------------
METHOD:       run_repl(session)
INPUT DATA:   сессия session (Ветвь 7)
OUTPUT DATA:  нет (цикл ввода-ответа до завершения)
FUNCTION:     цикл: read_line -> команда выхода или конец ввода
              завершают; пустая строка пропускается; иначе
              печатается line_output. Сессия одна на весь цикл —
              переменные и ans живут между строками
----------------------------------------------------------------
METHOD:       main()
INPUT DATA:   нет
OUTPUT DATA:  нет (запускает программу)
FUNCTION:     точка входа: печатает GREETING, создаёт сессию
              и входит в run_repl; вызывается из run.py
----------------------------------------------------------------
СВЯЗЬ С ДРУГИМИ ВЕТВЯМИ
