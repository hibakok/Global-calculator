================================================================
ВЕТВЬ 7. ПАМЯТЬ И ИСТОРИЯ: ПЕРЕМЕННЫЕ, ANS, СТЕК И ЖУРНАЛ
================================================================

Файл кода ветви: src/branch_7_memory.py
Собирается из методов Ветвей 3a (make_token), 6a (tokenize_scientific,
is_letter) и 6b (parse_expression_scientific, is_function,
is_constant). Существующие ветви не изменяются.

ЧАСТЬ 1. ПЕРЕМЕННЫЕ

Память — словарь «имя -> число». Словарь создаёт владелец (тест,
интерфейс) и передаёт методам параметром; глобального состояния
нет (docs/conventions.txt, раздел 6). Методы Ветви 7 могут
изменять переданный словарь.

ЧАСТЬ 2. СЕССИЯ: ANS, СТЕК И ЖУРНАЛ

Сессия — словарь из трёх ключей:
  "memory" — память переменных (часть 1);
  "stack"  — стек результатов вычислений;
  "log"    — журнал операций: пары (строка, результат).
ans — последний результат — хранится как обычная переменная
"ans" в памяти сессии, поэтому работает во всех выражениях без
новых механизмов подстановки: "ans * 2". Имя ans не
зарезервировано: присваивание "ans = 5" разрешено и будет
перезаписано следующим успешным вычислением. Ошибочное
вычисление не оставляет следов: ans, стек и журнал меняются
только после успеха. Стек и журнал не ограничены по размеру —
ограничение появится, когда его потребует интерфейс (Ветвь 9).

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       make_memory()
INPUT DATA:   нет
OUTPUT DATA:  пустой словарь — память калькулятора
FUNCTION:     создаёт новую независимую память; вызывается владельцем
              (тестом, интерфейсом) и make_session, а не методами
              ветви напрямую
----------------------------------------------------------------
METHOD:       find_equals(s)
INPUT DATA:   строка s
OUTPUT DATA:  целое число — позиция первого символа '=' или -1
FUNCTION:     находит знак присваивания; элементарный метод на
              встроенном find, как is_digit — на операторе in
----------------------------------------------------------------
METHOD:       is_valid_name(s)
INPUT DATA:   строка s
OUTPUT DATA:  True, если s — непустое имя из латинских букв, иначе False
FUNCTION:     проверяет левую часть присваивания; имена переменных
              подчиняются токенизатору Ветви 6a: только латинские
              буквы, без цифр и пробелов (x, speed, X)
----------------------------------------------------------------
METHOD:       split_assignment(s)
INPUT DATA:   строка s — выражение или присваивание "x = 2 + 2"
OUTPUT DATA:  пара (имя, выражение) без крайних пробелов или None,
              если '=' нет; при неверной левой части — исключение
              ValueError
FUNCTION:     делит строку присваивания по первому '='; цепочка
              "a = b = 1" делится по первому '=' и разбирается
              рекурсивно дальше (в calculate_with_memory)
----------------------------------------------------------------
METHOD:       is_reserved_name(name)
INPUT DATA:   строка name
OUTPUT DATA:  True, если имя занято константой (pi, e) или функцией
              (sqrt, exp, ln, sin, cos, tan), иначе False
FUNCTION:     защищает встроенные имена от присваивания: "sin = 2"
              и "pi = 3" отклоняются; собран из is_function и
              is_constant Ветви 6b; ans не входит — это обычная
              переменная
----------------------------------------------------------------
METHOD:       substitute_token(token, memory)
INPUT DATA:   токен — пара (тип, значение); память — словарь переменных
OUTPUT DATA:  токен: имя переменной заменено на ("number", значение),
              прочие токены возвращаются без изменений
FUNCTION:     подмена одного токена; зарезервированные имена не
              попадают в память, поэтому не подменяются
----------------------------------------------------------------
METHOD:       substitute_variables(tokens, memory)
INPUT DATA:   список токенов научного выражения; память — словарь
OUTPUT DATA:  новый список токенов, где имена переменных заменены
              числами
FUNCTION:     подготовка токенов к вычислению: "x * 3" при x = 4
              превращается в "4 * 3"; имена функций и констант
              сохраняются
----------------------------------------------------------------
METHOD:       evaluate_tokens(tokens)
INPUT DATA:   полный список научных токенов
OUTPUT DATA:  число — значение выражения; при пустом списке или
              лишних токенах в конце — исключение ValueError
FUNCTION:     вычисляет готовый список токенов научным парсером
              Ветви 6b (parse_expression_scientific) с проверкой
              конца разбора; хвост calculate_scientific,
              работающий с уже подготовленными токенами
----------------------------------------------------------------
METHOD:       assign_variable(name, rhs, memory)
INPUT DATA:   имя переменной; строка rhs — выражение; память
OUTPUT DATA:  число — вычисленное значение; память изменяется:
              memory[name] = значение
FUNCTION:     вычисляет правую часть через calculate_with_memory
              (поэтому цепочки "a = b = 2" работают) и сохраняет
              результат в память
----------------------------------------------------------------
METHOD:       calculate_with_memory(s, memory)
INPUT DATA:   строка s — выражение или присваивание; память — словарь
OUTPUT DATA:  число — значение выражения или присвоенное значение;
              память изменяется при присваивании
FUNCTION:     главная функция части 1: calculate_with_memory(
              "x = 2 + 2", m) = 4 и запоминает x = 4; затем
              calculate_with_memory("x * 3", m) = 12. Присваивание
              зарезервированных имён — ошибка; неизвестное имя
              в выражении — ошибка "Неизвестное имя" от парсера
              Ветви 6b; переменные работают и внутри вызовов
              функций: "sin(x)" при x = pi/2 равно 1
----------------------------------------------------------------
METHOD:       make_session()
INPUT DATA:   нет
OUTPUT DATA:  словарь {"memory": {}, "stack": [], "log": []} —
              пустая сессия калькулятора
FUNCTION:     создаёт новую независимую сессию; вызывается
              владельцем (тестом, интерфейсом Ветви 9), а не
              методами ветви; память сессии создаётся make_memory
----------------------------------------------------------------
METHOD:       remember_answer(session, value)
INPUT DATA:   сессия; число value — результат вычисления
OUTPUT DATA:  нет (сессия изменяется: memory["ans"] = value)
FUNCTION:     сохраняет последний результат; ans хранится
              переменной в памяти сессии, поэтому подмена имён
              Ветви 7 (substitute_variables) работает без
              изменений и "ans" доступен в любом выражении
----------------------------------------------------------------
METHOD:       push_result(session, value)
INPUT DATA:   сессия; число value — результат вычисления
OUTPUT DATA:  нет (сессия изменяется: stack.append(value))
FUNCTION:     добавляет результат в конец стека результатов;
              порядок стека — хронологический, от первого
              вычисления к последнему
----------------------------------------------------------------
METHOD:       log_operation(session, text, value)
INPUT DATA:   сессия; строка text — что вычисляли; число value —
              результат
OUTPUT DATA:  нет (сессия изменяется: log.append((text, value)))
FUNCTION:     добавляет запись в журнал операций; журнал хранит
              пары «строка — результат» в порядке вычислений
----------------------------------------------------------------
METHOD:       remember_result(session, text, value)
INPUT DATA:   сессия; строка text; число value — результат
OUTPUT DATA:  нет (сессия изменяется всеми тремя способами)
FUNCTION:     композиция трёх кирпичиков: remember_answer +
              push_result + log_operation; вызывается один раз
              после успешного вычисления
----------------------------------------------------------------
METHOD:       get_answer(session)
INPUT DATA:   сессия
OUTPUT DATA:  число — последний результат ans или None, если
              успешных вычислений ещё не было
FUNCTION:     чтение ans; None отличается от нуля, поэтому
              «пока ничего не вычисляли» видно сразу
----------------------------------------------------------------
METHOD:       get_results(session)
INPUT DATA:   сессия
OUTPUT DATA:  новый список — копия стека результатов
FUNCTION:     безопасное чтение стека: копия не позволяет
              вызывающей стороне испортить состояние сессии;
              порядок хронологический
----------------------------------------------------------------
METHOD:       get_log(session)
INPUT DATA:   сессия
OUTPUT DATA:  новый список — копия журнала: пары (строка, результат)
FUNCTION:     безопасное чтение журнала операций; копия, как
              get_results
----------------------------------------------------------------
METHOD:       calculate_session(s, session)
INPUT DATA:   строка s — выражение или присваивание; сессия
OUTPUT DATA:  число — значение выражения или присвоенное значение;
              сессия изменяется при успехе: ans, стек, журнал
FUNCTION:     главная функция части 2 и сессии: calculate_session(
              "2 + 2", session) = 4, затем calculate_session(
              "ans * 2", session) = 8; внутри — calculate_with_memory
              с памятью сессии, после успеха — remember_result;
              ошибка вычисления не оставляет следов в истории
