================================================================
ВЕТВЬ 7. ПАМЯТЬ И ИСТОРИЯ: ПЕРЕМЕННЫЕ
================================================================

Файл кода ветви: src/branch_7_memory.py
Собирается из методов Ветвей 3a (make_token), 6a (tokenize_scientific,
is_letter) и 6b (parse_expression_scientific, is_function,
is_constant). Существующие ветви не изменяются.

Память — словарь «имя -> число». Словарь создаёт владелец (тест,
интерфейс) и передаёт методам параметром; глобального состояния
нет (docs/conventions.txt, раздел 6). Методы Ветви 7 могут
изменять переданный словарь.

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       make_memory()
INPUT DATA:   нет
OUTPUT DATA:  пустой словарь — память калькулятора
FUNCTION:     создаёт новую независимую память; вызывается владельцем
              (тестом, интерфейсом), а не методами ветви
----------------------------------------------------------------
METHOD:       find_equals(s)
INPUT DATA:   строка s
OUTPUT DATA:  целое число — позиция первого символа '=' или -1
FUNCTION:     находит знак присваивания; элементарный метод на
              встроенном find, как is_digit — на операторе in
----------------------------------------------------------------
METHOD:       is_valid_name(s)
INPUT DATA:   строка s
OUTPUT DATA:  True, если s — непустое имя из латинских букв, иначе False
FUNCTION:     проверяет левую часть присваивания; имена переменных
              подчиняются токенизатору Ветви 6a: только латинские
              буквы, без цифр и пробелов (x, speed, X)
----------------------------------------------------------------
METHOD:       split_assignment(s)
INPUT DATA:   строка s — выражение или присваивание "x = 2 + 2"
OUTPUT DATA:  пара (имя, выражение) без крайних пробелов или None,
              если '=' нет; при неверной левой части — исключение
              ValueError
FUNCTION:     делит строку присваивания по первому '='; цепочка
              "a = b = 1" делится по первому '=' и разбирается
              рекурсивно дальше (в calculate_with_memory)
----------------------------------------------------------------
METHOD:       is_reserved_name(name)
INPUT DATA:   строка name
OUTPUT DATA:  True, если имя занято константой (pi, e) или функцией
              (sqrt, exp, ln, sin, cos, tan), иначе False
FUNCTION:     защищает встроенные имена от присваивания: "sin = 2"
              и "pi = 3" отклоняются; собран из is_function и
              is_constant Ветви 6b
----------------------------------------------------------------
METHOD:       substitute_token(token, memory)
INPUT DATA:   токен — пара (тип, значение); память — словарь переменных
OUTPUT DATA:  токен: имя переменной заменено на ("number", значение),
              прочие токены возвращаются без изменений
FUNCTION:     подмена одного токена; зарезервированные имена не
              попадают в память, поэтому не подменяются
----------------------------------------------------------------
METHOD:       substitute_variables(tokens, memory)
INPUT DATA:   список токенов научного выражения; память — словарь
OUTPUT DATA:  новый список токенов, где имена переменных заменены
              числами
FUNCTION:     подготовка токенов к вычислению: "x * 3" при x = 4
              превращается в "4 * 3"; имена функций и констант
              сохраняются
----------------------------------------------------------------
METHOD:       evaluate_tokens(tokens)
INPUT DATA:   полный список научных токенов
OUTPUT DATA:  число — значение выражения; при пустом списке или
              лишних токенах в конце — исключение ValueError
FUNCTION:     вычисляет готовый список токенов научным парсером
              Ветви 6b (parse_expression_scientific) с проверкой
              конца разбора; хвост calculate_scientific,
              работающий с уже подготовленными токенами
----------------------------------------------------------------
METHOD:       assign_variable(name, rhs, memory)
INPUT DATA:   имя переменной; строка rhs — выражение; память
OUTPUT DATA:  число — вычисленное значение; память изменяется:
              memory[name] = значение
FUNCTION:     вычисляет правую часть через calculate_with_memory
              (поэтому цепочки "a = b = 2" работают) и сохраняет
              результат в память
----------------------------------------------------------------
METHOD:       calculate_with_memory(s, memory)
INPUT DATA:   строка s — выражение или присваивание; память — словарь
OUTPUT DATA:  число — значение выражения или присвоенное значение;
              память изменяется при присваивании
FUNCTION:     главная функция ветви: calculate_with_memory(
              "x = 2 + 2", m) = 4 и запоминает x = 4; затем
              calculate_with_memory("x * 3", m) = 12. Присваивание
              зарезервированных имён — ошибка; неизвестное имя
              в выражении — ошибка "Неизвестное имя" от парсера
              Ветви 6b; переменные работают и внутри вызовов
              функций: "sin(x)" при x = pi/2 равно 1
