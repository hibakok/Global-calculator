МЕТОДЫ ВЕТВИ

METHOD:       power_int(a, n)
INPUT DATA:   число a (int или float); целое число n (int), n >= 0
OUTPUT DATA:  число (int или float) — a в степени n
FUNCTION:     возводит a в целую неотрицательную степень n,
              многократно применяя multiply из Ветви 1;
              при n < 0 возникает исключение ValueError
