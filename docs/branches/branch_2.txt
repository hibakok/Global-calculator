Файл кода ветви: src/branch_2_extended.py

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       power_int(a, n)
INPUT DATA:   число a (int или float); целое число n (int), n >= 0
OUTPUT DATA:  число (int или float) — a в степени n
FUNCTION:     возводит a в целую неотрицательную степень n,
              многократно применяя multiply из Ветви 1;
              при n < 0 возникает исключение ValueError
----------------------------------------------------------------
METHOD:       int_divide(a, b)
INPUT DATA:   два числа a и b (int или float); b не должен быть нулём
OUTPUT DATA:  целая часть частного a / b, округлённая вниз
              (int для целых входов); при b == 0 — исключение ZeroDivisionError
FUNCTION:     вычисляет целочисленное частное с округлением вниз:
              int_divide(7, 2) = 3; int_divide(-7, 2) = -4.
              Элементарный метод уровня Ветви 1: построен на встроенном
              операторе целочисленного деления, как add построен на «+».
              Повторное вычитание не применяется: на больших числах
              оно непрактично.
----------------------------------------------------------------
METHOD:       remainder(a, b)
INPUT DATA:   два числа a и b (int или float); b не должен быть нулём
OUTPUT DATA:  число (int или float) — остаток от деления a на b;
              при b == 0 — исключение ZeroDivisionError
FUNCTION:     вычисляет остаток от деления: remainder(7, 2) = 1;
              remainder(-7, 2) = 1 (согласовано с int_divide:
              -7 = 2 * (-4) + 1). Элементарный метод уровня Ветви 1:
              построен на встроенном операторе остатка «%»,
              как int_divide построен на «//».
