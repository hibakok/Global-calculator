================================================================
ВЕТВЬ 3A. РАЗБОР ВЫРАЖЕНИЙ: ТОКЕНИЗАТОР
================================================================

Файл кода ветви: src/branch_3a_tokenizer.py
Нижний уровень Ветви 3. Превращает строку выражения в список
токенов. Не опирается на другие ветви (только встроенный Python).

Токен — пара (тип, значение). Типы токенов:
  "number"      значение int (целое) или float (с точкой)
  "operator"    значение "+", "-", "*", "/", "%", "^"
  "left_paren"  открывающая скобка "("
  "right_paren" закрывающая скобка ")"

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       is_digit(c)
INPUT DATA:   один символ c (строка длины 1)
OUTPUT DATA:  True, если символ — цифра, иначе False
FUNCTION:     проверяет, что символ является десятичной цифрой
              от 0 до 9
----------------------------------------------------------------
METHOD:       is_space(c)
INPUT DATA:   один символ c (строка длины 1)
OUTPUT DATA:  True, если символ — пробельный, иначе False
FUNCTION:     проверяет, что символ является пробелом,
              табуляцией или переводом строки
----------------------------------------------------------------
METHOD:       is_operator(c)
INPUT DATA:   один символ c (строка длины 1)
OUTPUT DATA:  True, если символ — знак операции, иначе False
FUNCTION:     проверяет, что символ — одна из операций + - * / % ^
----------------------------------------------------------------
METHOD:       skip_spaces(s, i)
INPUT DATA:   строка s; начальная позиция i (int)
OUTPUT DATA:  индекс (int) первого непробельного символа,
              начиная с позиции i; если пробелы идут до конца —
              длина строки
FUNCTION:     продвигает позицию вперёд, минуя пробельные символы
----------------------------------------------------------------
METHOD:       read_digits(s, i)
INPUT DATA:   строка s; позиция i (int), где ожидается цифра
OUTPUT DATA:  позиция (int), идущая за последовательностью цифр,
              начатой в позиции i
FUNCTION:     находит конец последовательности цифр в строке
----------------------------------------------------------------
METHOD:       read_number(s, i)
INPUT DATA:   строка s; позиция i (int), где начинается число
OUTPUT DATA:  пара (число, следующая позиция): число int, если
              нет десятичной точки, и float, если есть; следующая
              позиция — индекс символа сразу после числа
FUNCTION:     читает из строки неотрицательное число: цифры,
              затем, возможно, точка и ещё цифры. Точка без цифры
              после неё числом не считается ("5." читается как 5,
              точка остаётся). Собран из кирпичиков read_digits
              и is_digit
----------------------------------------------------------------
METHOD:       make_token(kind, value)
INPUT DATA:   тип токена kind (строка) и значение value
OUTPUT DATA:  токен — пара (kind, value)
FUNCTION:     создаёт токен из типа и значения
----------------------------------------------------------------
METHOD:       read_token(s, i)
INPUT DATA:   строка s; позиция i (int), где ожидается начало
              токена (не пробел)
OUTPUT DATA:  пара (токен, следующая позиция); при недопустимом
              символе — исключение ValueError
FUNCTION:     читает один токен: число (read_number), знак
              операции, скобку. Собран из кирпичиков is_digit,
              is_operator, read_number, make_token
----------------------------------------------------------------
METHOD:       tokenize(s)
INPUT DATA:   строка s с арифметическим выражением
OUTPUT DATA:  список токенов (пустой, если строка пустая или из
              одних пробелов); при недопустимом символе —
              исключение ValueError
FUNCTION:     превращает всю строку в список токенов; пробелы
              между токенами игнорируются. Собран из кирпичиков
              skip_spaces и read_token
