================================================================
ВЕТВЬ 4. НАУЧНЫЕ ФУНКЦИИ: ЭКСПОНЕТА И ЛОГАРИФМ
================================================================

Файл кода ветви: src/branch_4_scientific.py
Научный блок калькулятора собственными силами: модуль, знак,
квадратный корень, экспонента, число e, натуральный логарифм
и вещественная степень. Собирается из Ветвей 1 и 2; ряды и
итерации пишутся сами, без сторонних библиотек.

Тригонометрия и число пи живут в отдельной Ветви 5.

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       abs_value(x)
INPUT DATA:   число x (int или float)
OUTPUT DATA:  число — модуль x
FUNCTION:     возвращает модуль числа: abs_value(-3) = 3,
              abs_value(3) = 3, abs_value(0) = 0. Элементарный
              метод уровня Ветви 1: построен на сравнении и
              унарном минусе, как add построен на «+»
----------------------------------------------------------------
METHOD:       sign(x)
INPUT DATA:   число x (int или float)
OUTPUT DATA:  целое число: -1, 0 или 1
FUNCTION:     возвращает знак числа: sign(-5) = -1, sign(0) = 0,
              sign(5) = 1. Элементарный метод: два сравнения
----------------------------------------------------------------
METHOD:       sqrt_real(x)
INPUT DATA:   неотрицательное число x (int или float); для nan —
              nan
OUTPUT DATA:  число — квадратный корень из x; при x < 0 —
              исключение ValueError; при nan — nan
FUNCTION:     вещественный квадратный корень методом Ньютона:
              y → (y + x / y) / 2 из начального приближения
              (x + 1) / 2. Цикл останавливается, когда очередное
              приближение перестаёт строго уменьшаться — условие
              вида not (nxt < y) гарантирует конец также на nan
              (возвращает nan вместо вечного цикла). Собран из
              кирпичиков add и divide Ветви 1: sqrt_real(4) = 2,
              sqrt_real(2) ≈ 1.41421356
----------------------------------------------------------------
METHOD:       exp_series(x)
INPUT DATA:   число x (int или float), по модулю не больше 1
OUTPUT DATA:  число (float) — сумма ряда 1 + x + x^2/2! + ...;
              при nan — nan
FUNCTION:     суммирует ряд Тейлора экспоненты: каждый следующий
              член получается из предыдущего делением на n
              (рекуррентно, без вычисления факториалов). Остано-
              вливается, когда член становится пренебрежимо мал
              относительно суммы (меньше 1e-16 от неё); условие
              вида not (больше) гарантирует конец на nan. Для
              |x| <= 1 сходится за ~20 членов. Собран из
              кирпичиков add, multiply, divide, abs_value
----------------------------------------------------------------
METHOD:       exp_real(x)
INPUT DATA:   любое вещественное число x (int, float, inf, nan)
OUTPUT DATA:  число (float) — e в степени x; exp_real(inf) = inf,
              exp_real(-inf) = 0; при переполнении — inf;
              при nan — nan
FUNCTION:     экспонента любого вещественного аргумента: сначала
              аргумент делится на 2, пока не станет по модулю
              не больше 1 (деление на 2 точно в двоичной
              арифметике), затем считается exp_series и результат
              возводится в квадрат столько же раз. Относительная
              погрешность не хуже ~1e-12 даже на больших
              аргументах (например, exp_real(700)). Собран из
              exp_series, abs_value, divide, multiply
----------------------------------------------------------------
METHOD:       get_e()
INPUT DATA:   нет
OUTPUT DATA:  число (float) — основание натурального логарифма e
FUNCTION:     возвращает число e как exp_real(1) — сумму ряда
              в точке 1: get_e() ≈ 2.718281828459045 (точность
              до последнего знака двойной точности)
----------------------------------------------------------------
METHOD:       ln_series(u)
INPUT DATA:   число u (int или float) из интервала (-1, 1);
              на практике |u| <= 1/2
OUTPUT DATA:  число (float) — сумма ряда u - u^2/2 + u^3/3 - ...,
              то есть ln(1 + u); при u <= -1 или u >= 1 —
              исключение ValueError; при nan — nan
FUNCTION:     суммирует ряд Тейлора логарифма: каждый следующий
              член получается из предыдущего умножением на u и
              на k/(k+1) со сменой знака. Границы интервала
              отвергаются явно: на них ряд сходится бесконечно
              долго, а внутри — за ~60 членов при |u| = 1/2.
              Собран из add, subtract, multiply, divide, abs_value
----------------------------------------------------------------
METHOD:       get_ln2()
INPUT DATA:   нет
OUTPUT DATA:  число (float) — натуральный логарифм числа 2
FUNCTION:     возвращает ln(2) как 2 * ln_series(sqrt(2) - 1):
              корень из двух приводится к 1 минус малое
              отклонение. get_ln2() ≈ 0.6931471805599453
              (точность до последнего знака двойной точности).
              Собран из ln_series, sqrt_real, subtract, multiply
----------------------------------------------------------------
METHOD:       ln_positive(x)
INPUT DATA:   положительное число x (int, float, inf, nan)
OUTPUT DATA:  число (float) — натуральный логарифм x;
              ln_positive(inf) = inf; при x <= 0 — исключение
              ValueError; при nan — nan
FUNCTION:     натуральный логарифм: число x делится (или умно-
              жается) на 2, пока не попадёт в отрезок [0.75; 1.5]
              — эти операции точны в двоичной арифметике и не
              накапливают ошибку; затем ln_series(y - 1), а
              результат складывается с get_ln2() * число делений.
              Относительная погрешность ~1e-15 на всём диапазоне
              от 5e-324 до 1e308. Собран из ln_series, get_ln2,
              add, subtract, multiply, divide
----------------------------------------------------------------
METHOD:       power_real(a, b)
INPUT DATA:   число a (основание) и число b (показатель);
              int, float, inf, nan
OUTPUT DATA:  число — a в степени b. Целый показатель (включая
              целые значения float и отрицательные) вычисляется
              точно через power_int Ветви 2. Дробный показатель:
              exp_real(b * ln_positive(a)). power_real(0, 0) = 1;
              при a = 0 и b < 0 — ZeroDivisionError; при
              a < 0 и нецелом b — ValueError; при nan — nan;
              при переполнении — inf
FUNCTION:     вещественная степень: положительное основание —
              через экспоненту и логарифм (погрешность ~1e-15),
              целые показатели — точно целочисленным возведением,
              отрицательное основание допускается только в целой
              степени. Собран из power_int, exp_real, ln_positive,
              add, subtract, multiply, divide
----------------------------------------------------------------
ЗАМЕЧАНИЕ О ТОЧНОСТИ

Погрешности измерены сравнением с эталоном (модуль math
стандартной библиотеки, см. тесты): ln_series, get_ln2,
ln_positive, power_real и get_e — около 5e-16 (последний знак
двойной точности); exp_series — около 3e-16; exp_real — не хуже
2e-13 (накопление при многократном возведении в квадрат на
больших аргументах).
