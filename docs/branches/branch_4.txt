================================================================
ВЕТВЬ 4. НАУЧНЫЕ ФУНКЦИИ
================================================================

Файл кода ветви: src/branch_4_scientific.py
Научный блок калькулятора собственными силами: модуль, знак,
квадратный корень, экспонента, логарифм, тригонометрия,
константы pi и e, вещественная степень. Собирается из Ветвей 1-3;
ряды и итерации пишутся сами, без сторонних библиотек.

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       abs_value(x)
INPUT DATA:   число x (int или float)
OUTPUT DATA:  число — модуль x
FUNCTION:     возвращает модуль числа: abs_value(-3) = 3,
              abs_value(3) = 3, abs_value(0) = 0. Элементарный
              метод уровня Ветви 1: построен на сравнении и
              унарном минусе, как add построен на «+»
----------------------------------------------------------------
METHOD:       sign(x)
INPUT DATA:   число x (int или float)
OUTPUT DATA:  целое число: -1, 0 или 1
FUNCTION:     возвращает знак числа: sign(-5) = -1, sign(0) = 0,
              sign(5) = 1. Элементарный метод: два сравнения
