================================================================
ВЕТВЬ 8. ПРЕОБРАЗОВАНИЯ. ЧАСТЬ 1: СИСТЕМЫ СЧИСЛЕНИЯ
================================================================

Файл кода ветви: src/branch_8_conversions.py
Собирается из методов Ветвей 1 (add, subtract, multiply) и 2
(int_divide, remainder). Существующие ветви не изменяются.

Система счисления задаётся основанием — целым числом от 2 до 36.
Цифры: 0-9 и a-z; при вводе регистр букв не важен ("FF" = "ff"),
при выводе всегда строчные буквы. Перевод работает в обе стороны
и собирается из двух цепочек кирпичиков:

  число -> значения цифр -> строка     to_base_string
  строка -> значения цифр -> число     from_base_string

Главная функция convert_base соединяет цепочки: перевод записи
числа между любыми двумя основаниями, например
convert_base("ff", 16, 2) = "11111111".

КОНСТАНТА: DIGITS — строка "0123456789abcdefghijklmnopqrstuvwxyz"
  (все 36 цифр). Значение цифры равно позиции её символа в строке.
  Константа неизменяемая, глобального изменяемого состояния нет
  (docs/conventions.txt, раздел 6).

----------------------------------------------------------------
МЕТОДЫ ВЕТВИ

METHOD:       digit_char(value)
INPUT DATA:   целое число value от 0 до 35
OUTPUT DATA:  одиночный символ — цифра с этим значением: "0"-"9",
              "a"-"z"; при выходе из диапазона — ValueError
FUNCTION:     значение -> символ; обратная пара digit_value
----------------------------------------------------------------
METHOD:       digit_value(char)
INPUT DATA:   одиночный символ char
OUTPUT DATA:  целое число от 0 до 35 — значение цифры: "0"-"9" ->
              0-9, "a"-"z" и "A"-"Z" -> 10-35; для не-цифры,
              пустой строки или нескольких символов — ValueError
FUNCTION:     символ -> значение; регистр букв не важен
----------------------------------------------------------------
METHOD:       check_base(base)
INPUT DATA:   основание системы счисления base
OUTPUT DATA:  то же основание; для не-целого — TypeError,
              для значения вне 2-36 — ValueError
FUNCTION:     защита всех методов ветви от неверного основания;
              вызывается главными функциями to_base_string
              и from_base_string
----------------------------------------------------------------
METHOD:       check_integer(n)
INPUT DATA:   число n
OUTPUT DATA:  то же число; для не-целого (например 2.5) — TypeError
FUNCTION:     защита to_base_string от дробных чисел: перевод
              между системами счисления определён только для целых
----------------------------------------------------------------
METHOD:       is_base_digit(char, base)
INPUT DATA:   одиночный символ char; основание base от 2 до 36
OUTPUT DATA:  True, если символ — допустимая цифра этой системы
              счисления, иначе False
FUNCTION:     предикат допустимости цифры: "f" допустимо при
              основании 16 и недопустимо при основании 10;
              собран на срезке DIGITS[:base]
----------------------------------------------------------------
METHOD:       check_base_digit(char, base)
INPUT DATA:   одиночный символ char; основание base от 2 до 36
OUTPUT DATA:  значение цифры от 0 до base-1; если символ не
              является цифрой этой системы — ValueError
FUNCTION:     проверка и значение одним вызовом — кирпичик схемы
              Горнера в from_base_digits; собран из is_base_digit
              и digit_value
----------------------------------------------------------------
METHOD:       to_base_values(n, base)
INPUT DATA:   целое число n >= 0; основание base от 2 до 36
OUTPUT DATA:  список значений цифр числа n от младшей цифры
              к старшей; to_base_values(5, 2) = [1, 0, 1];
              для отрицательного n — ValueError
FUNCTION:     цикл деления: каждый шаг срезает младшую цифру
              остатком remainder и уменьшает число целой частью
              int_divide; завершается при n = 0 (раздел 10
              конвенций); n = 0 даёт [0]
----------------------------------------------------------------
METHOD:       values_to_string(values)
INPUT DATA:   список значений цифр от старшей к младшей
OUTPUT DATA:  строка цифр; values_to_string([15, 15]) = "ff";
              пустой список даёт пустую строку
FUNCTION:     собирает строку из символов digit_char
----------------------------------------------------------------
METHOD:       to_base_positive(n, base)
INPUT DATA:   целое число n >= 0; основание base от 2 до 36
OUTPUT DATA:  строка цифр числа n по основанию base;
              to_base_positive(0, 2) = "0"
FUNCTION:     соединяет to_base_values (младшая -> старшая),
              переворот list(reversed(...)) и values_to_string;
              знак не обрабатывает — это делает to_base_string
----------------------------------------------------------------
METHOD:       to_base_string(n, base)
INPUT DATA:   целое число n (любого знака); основание base
OUTPUT DATA:  строка цифр числа n по основанию base со знаком
              "минус" для отрицательных: to_base_string(-255, 16)
              = "-ff"; для дробного n — TypeError, для неверного
              основания — ValueError
FUNCTION:     главная функция перевода в систему счисления:
              проверяет основание и целость, отрицательное число
              переводит через вычитание subtract(0, n) Ветви 1
              (как унарный минус в Ветви 6b)
----------------------------------------------------------------
METHOD:       split_sign(s)
INPUT DATA:   строка s — запись числа со знаком или без
OUTPUT DATA:  пара (знак: -1 или 1, строка цифр без знака
              и крайних пробелов); split_sign("  - ff ") =
              (-1, "ff"); пустая строка и пробелы — ValueError,
              не-строка — TypeError
FUNCTION:     отделяет знак от цифр; пробелы вокруг знака и цифр
              допускаются, пробелы между цифрами — нет
----------------------------------------------------------------
METHOD:       from_base_digits(digits, base)
INPUT DATA:   строка цифр digits от старшей к младшей; основание
              base от 2 до 36
OUTPUT DATA:  целое число — значение записи; from_base_digits(
              "ff", 16) = 255; пустая строка даёт 0; недопустимая
              для основания цифра — ValueError
FUNCTION:     схема Горнера из кирпичиков Ветви 1: total =
              add(multiply(total, base), цифра); цикл по конечной
              строке всегда завершается
----------------------------------------------------------------
METHOD:       from_base_string(s, base)
INPUT DATA:   строка s — запись целого числа в системе счисления
              с основанием base; допускаются знак "+" или "-",
              оба регистра букв и крайние пробелы
OUTPUT DATA:  целое число: from_base_string("ff", 16) = 255,
              from_base_string("-ff", 16) = -255; пустая строка,
              только знак, пробел между цифрами, недопустимая
              цифра — ValueError; не-строка — TypeError
FUNCTION:     главная функция перевода из системы счисления:
              check_base, split_sign, проверка наличия цифр,
              from_base_digits и знак через subtract(0, value)
----------------------------------------------------------------
METHOD:       convert_base(s, from_base, to_base)
INPUT DATA:   строка s — запись целого числа в системе с
              основанием from_base; целевое основание to_base
              (оба от 2 до 36)
OUTPUT DATA:  строка — запись того же числа по основанию to_base:
              convert_base("ff", 16, 2) = "11111111",
              convert_base("-ff", 16, 10) = "-255"; ошибки
              входной записи — как у from_base_string
FUNCTION:     главная функция части 1: соединяет две цепочки
              кирпичиков from_base_string и to_base_string —
              перевод между любыми двумя основаниями
